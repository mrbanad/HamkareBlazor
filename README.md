# HamkareBlazor
### A feature-extended fork of MudBlazor with additional enhancements, improved defaults, and full Persian support

**HamkareBlazor** is a customized and extended version of **MudBlazor**.  
The goal of this project is to provide a set of Blazor components that:

- Are easier to use for developers, especially Persian-speaking users
- Include optimized default values for faster development
- Address certain limitations of the original MudBlazor
- Add new practical features
- Allow independent development and management without relying on official releases

> This project is originally based on MudBlazor and maintains its professional structure, standards, and reliability.

---

## ✨ Project Goals

- Introduce new features required for real-world projects
- Simplify development for Persian language support (RTL, Persian Localization)
- Provide optimized default values for common scenarios
- Improve UX of components for faster development
- Package all modifications into an independent library (HamkareBlazor)
- Retain MudBlazor’s core structure to ensure stability and quality
